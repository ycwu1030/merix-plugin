# Changelog

## 0.1.0

Initial public release of MERIX Research Plugin.

### Included

- Research-project initialization, adoption, compatible extension and
  confirmed baseline updates with preservation and recovery reporting.
- Three Skills for project initialization, artifact management and local runs.
- Project-local task, relation, dependency, focus and handoff tools.
- Structural evidence checks and monotonically allocated Formula Index IDs.
- Work-package/Run records and explicitly authorized local detached execution.
- Artifact registration, discovery, storage, integrity checks and cleanup.
- Required Markdown formatter Hook with supported normalization, protected
  code/control files and source-preserving diagnostics.
- MIT license, Plugin ID `merix-research` and marketplace `merix`.

### Compatibility and migration

- Updating the Plugin does not update existing research-project baselines.
- Previous `research-agents` installs retain their identity; inspect and
  disable duplicates before enabling the new formatter Hook.
- Taskboard is optional; the local workflow is standalone.
- Additional platforms, writer clients and automatic scheduling are outside
  this initial compatibility claim. See the README for tested versions.
