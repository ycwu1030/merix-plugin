2. Create or update a permanent task record when work is independently trackable, evidence-bearing, parallel, pausable, or handoffable.
3. Preserve sources, derivations, code, results, and limitations in their authoritative records; update the compact context/status entry points after meaningful outcomes.
4. Obtain explicit confirmation before high-cost computation, sensitive-data handling outside the request, material scope/assumption/convention changes, external communication, or destructive actions.
